● Repo อยู่ในโฟลเดอร์นี้แล้ว (มี .venv กับ glidre.egg-info ด้วย) แต่ถ้าจะทำใหม่ด้วย uv
  ให้รันตามนี้:

  1. ดาวน์โหลด (ถ้ายังไม่มี)
  git clone https://github.com/robinarmingaud/glidre.git
  cd glidre

  2. สร้าง venv + ติดตั้ง dependencies
  uv venv
  uv pip install .

  3. รัน
  uv run python3 -c "
  from glidre import GLiDRE
  model = GLiDRE.from_pretrained('cea-list-ia/glidre_large')
  text = 'The Loud Tour was the fourth overall and third world concert tour by 
  Barbadian recording artist Rihanna.'
  labels = ['COUNTRY_OF_CITIZENSHIP', 'PUBLICATION_DATE', 'PART_OF']
  mentions = [
    {'id': 0, 'type': 'LOC', 'mentions': [{'value': 'Barbadian', 'start': 69, 
  'end': 78}]},
    {'id': 1, 'type': 'PER', 'mentions': [{'value': 'Rihanna', 'start': 96, 
  'end': 103}]},
  ]
  for r in model.predict_entities(text=text, labels=labels, mentions=mentions, 
  threshold=0.3, multi_label=False):
      print(r['entity_1'], '|', r['relation_type'], '|', r['entity_2'])
  "

  เทรน (ถ้าต้องการ)
  uv run python3 train.py --config configs/config_finetuning.yaml

  หมายเหตุ: uv pip install . จะดึง torch ตัวเต็มจาก PyPI (ใหญ่ ~2GB+) ถ้าเครื่องมี CUDA
  อยากได้เวอร์ชัน GPU ให้ติดตั้ง uv pip install torch --index-url 
  https://download.pytorch.org/whl/cu121 ก่อนค่อย uv pip install . ครับ
